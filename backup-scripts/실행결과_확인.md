## ⚠️ 추가 설정 필요 항목

### 1. rsync 설치 (필수)

**⚠️ 중요: 로컬 PC WSL에 rsync가 없습니다!**

**현재 상태**: 로컬 PC WSL에 rsync가 설치되어 있지 않음

**설치 위치**: 로컬 PC WSL 터미널

**설치 방법**:
```bash
# 로컬 PC WSL 터미널에서 실행
sudo dnf install -y rsync
```

**설치 확인**:
```bash
which rsync
rsync --version
```

**참고**:
- 외부 서버의 rsync는 필요하지 않습니다 (서버는 백업 파일만 생성)
- 로컬 PC WSL에서 rsync 클라이언트가 필요합니다 (외부 서버에서 백업 가져오기)

---

### 2. SSH 키 생성 (필수)

**현재 상태**: SSH 키 파일이 없음

**⚠️ 중요: 로컬 PC WSL 터미널에서 실행해야 합니다!**

백업 시스템은 **로컬 PC WSL에서 외부 서버로 접속**하므로, SSH 키는 **WSL에서 생성**하고 **외부 서버에 공개키를 등록**해야 합니다.

**실행 위치**: 로컬 PC WSL 터미널

**SSH 키 생성 및 서버 등록**:
```bash
# 1. SSH 키 생성 (로컬 PC WSL에서 실행)
ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa_backup -N ""

# 2. 서버에 공개키 복사 (로컬 PC WSL에서 실행)
#    이 명령은 외부 서버의 ~/.ssh/authorized_keys에 공개키를 자동으로 추가합니다
ssh-copy-id -i ~/.ssh/id_rsa_backup.pub root@172.234.92.172

# 3. 연결 테스트 (로컬 PC WSL에서 실행)
ssh -i ~/.ssh/id_rsa_backup root@172.234.92.172 "echo 'Connection successful'"
```

**동작 원리**:
- 로컬 PC WSL (클라이언트) → SSH 키 생성
- 로컬 PC WSL (클라이언트) → 외부 서버로 공개키 복사
- 이후 비밀번호 없이 외부 서버에 접속 가능
- rsync 백업 시 비밀번호 입력 없이 자동 실행
