## 1. 현재 상황 분석

### 1.1 사용 중인 Google Fonts

**style.css에서 로드 중인 폰트:**

1. **Noto Sans (다국어)** - 가장 중요
   - 언어별: KR, JP, SC, TC, HK
   - 굵기: 100, 200, 300, 400, 500, 600, 700, 800, 900
   - 스타일: Regular, Italic
   - **예상 파일 크기**: ~15-25MB (모든 언어 포함)

2. **Montserrat**
   - 굵기: 100~900
   - **예상 파일 크기**: ~1-2MB

3. **Lato**
   - 굵기: 100~900
   - 스타일: Regular, Italic
   - **예상 파일 크기**: ~2-3MB

4. **Poppins**
   - 굵기: 100~900
   - 스타일: Regular, Italic
   - **예상 파일 크기**: ~2-3MB

**총 예상 파일 크기**: 20-33MB (모든 변형 포함)

### 1.2 현재 로드 방식의 문제점

```css
/* 현재: CSS @import (블로킹) */
@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+...');
```

**문제점:**
1. **DNS 조회 지연**: fonts.googleapis.com 도메인 해석 필요
2. **외부 네트워크 요청**: CDN 서버 응답 대기
3. **블로킹 로드**: CSS @import는 렌더링 블로킹
4. **지역별 속도 차이**: 일부 지역에서 Google CDN 접근 지연
5. **추가 네트워크 홉**: 브라우저 → Google CDN → 폰트 파일

## 2. 로컬 폰트 사용의 장단점

### 2.1 장점 ✅

1. **네트워크 요청 감소**
   - DNS 조회 불필요 (fonts.googleapis.com)
   - 외부 CDN 요청 제거
   - 같은 서버에서 로드 (이미 연결되어 있음)

2. **로드 속도 개선**
   - CDN 지연 없음
   - 지역별 차이 최소화
   - 초기 연결 오버헤드 감소

3. **안정성 향상**
   - 외부 서비스 의존성 제거
   - CDN 장애 시 영향 없음
   - 오프라인 테스트 가능

4. **캐싱 제어**
   - 서버 캐싱 정책 직접 제어
   - 브라우저 캐싱 최적화 가능

5. **프라이버시**
   - 사용자 IP가 Google로 전송되지 않음

### 2.2 단점 ⚠️

1. **초기 설정 작업**
   - 폰트 파일 다운로드
   - @font-face CSS 작성
   - 파일 관리 필요

2. **서버 저장 공간**
   - 20-33MB 정도의 저장 공간 필요
   - 크지만 감당 가능한 수준

3. **서버 대역폭**
   - 폰트 로드를 서버에서 제공
   - 하지만 한 번만 다운로드되고 캐시됨

4. **업데이트 관리**
   - 폰트 업데이트 시 수동으로 교체 필요

## 3. 성능 개선 효과 예측

### 3.1 로드 시간 비교

**현재 (Google CDN):**
- DNS 조회: 20-100ms
- CDN 연결: 50-200ms (지역별 차이 큼)
- CSS 다운로드: 50-150ms
- 폰트 파일 다운로드: 100-500ms (캐시되지 않은 경우)
- **총 예상 시간**: 220-950ms

**로컬 폰트:**
- DNS 조회: 0ms (같은 서버)
- 서버 연결: 0ms (이미 연결됨)
- CSS 다운로드: 10-50ms
- 폰트 파일 다운로드: 50-200ms (캐시되지 않은 경우)
- **총 예상 시간**: 60-250ms

**개선 효과**: **160-700ms 단축** (약 27-73% 개선)

### 3.2 특히 효과적인 경우

1. **느린 네트워크 환경** (2G, 3G)
   - 외부 CDN 접근 지연이 큰 경우
   - 개선 효과가 더욱 큼

2. **Google CDN 접근이 느린 지역**
   - 동남아시아, 아프리카 등 일부 지역
   - 지역별 CDN 캐시 미스 시

3. **First Page Load**
   - 캐시되지 않은 첫 방문자
   - 모든 외부 리소스가 새로 로드되는 경우

## 4. 구현 방안

### 4.1 폴더 구조

```
/var/www/html/mekeng.com/public/fonts/
├── noto-sans/
│   ├── NotoSansKR/
│   │   ├── NotoSansKR-Regular.woff2
│   │   ├── NotoSansKR-Medium.woff2
│   │   ├── NotoSansKR-Bold.woff2
│   │   └── ...
│   ├── NotoSansJP/
│   ├── NotoSansSC/
│   ├── NotoSansTC/
│   └── NotoSansHK/
├── montserrat/
│   ├── Montserrat-Regular.woff2
│   └── ...
├── lato/
└── poppins/
```

### 4.2 필요한 폰트만 선택적으로 다운로드

**권장 접근 방식:**
- **Noto Sans KR**: 한국어 사이트에 필수
- **Noto Sans JP**: 일본어 사이트
- **Noto Sans SC**: 중국어 사이트 (간체)
- **Noto Sans TC**: 중국어 사이트 (번체)
- **Noto Sans HK**: 홍콩 사이트

**굵기 최적화:**
- 모든 굵기(100-900) 대신 실제 사용하는 굵기만
- 일반적으로: 300 (Light), 400 (Regular), 500 (Medium), 700 (Bold)
- **파일 크기 60-70% 감소 가능**

### 4.3 @font-face CSS 생성

**fonts.css 파일 생성 예시:**

```css
/* Noto Sans KR */
@font-face {
  font-family: 'Noto Sans KR';
  font-style: normal;
  font-weight: 300;
  font-display: swap;
  src: url('/public/fonts/noto-sans/NotoSansKR/NotoSansKR-Light.woff2') format('woff2');
}

@font-face {
  font-family: 'Noto Sans KR';
  font-style: normal;
  font-weight: 400;
  font-display: swap;
  src: url('/public/fonts/noto-sans/NotoSansKR/NotoSansKR-Regular.woff2') format('woff2');
}

@font-face {
  font-family: 'Noto Sans KR';
  font-style: normal;
  font-weight: 500;
  font-display: swap;
  src: url('/public/fonts/noto-sans/NotoSansKR/NotoSansKR-Medium.woff2') format('woff2');
}

@font-face {
  font-family: 'Noto Sans KR';
  font-style: normal;
  font-weight: 700;
  font-weight: 700;
  font-display: swap;
  src: url('/public/fonts/noto-sans/NotoSansKR/NotoSansKR-Bold.woff2') format('woff2');
}

/* 다른 언어별 폰트도 동일하게... */
```

**font-display: swap** 사용 이유:
- 폰트 로드 전에도 텍스트가 즉시 표시됨
- FOIT (Flash of Invisible Text) 방지
- 사용자 경험 개선

### 4.4 style.css 수정

**변경 전:**
```css
@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+KR:...');
```

**변경 후:**
```css
@import url('/public/css/fonts.css');
```

또는 **더 나은 방법** (head.sub.php에서):
```php
add_stylesheet('<link rel="stylesheet" href="'.G5_URL.'/public/css/fonts.css">', 0);
```

## 5. 폰트 다운로드 방법

### 5.1 Google Fonts에서 직접 다운로드

1. **Google Fonts 웹사이트 방문**
   - https://fonts.google.com/

2. **필요한 폰트 선택**
   - Noto Sans KR, JP, SC, TC, HK
   - Montserrat, Lato, Poppins

3. **폰트 다운로드**
   - 각 폰트의 "Download family" 버튼 클릭
   - ZIP 파일 다운로드

4. **폰트 추출 및 변환**
   - ZIP 압축 해제
   - TTF 파일을 WOFF2로 변환 (권장)
   - 온라인 변환 도구: https://cloudconvert.com/ttf-to-woff2

### 5.2 자동화 스크립트 사용

**google-webfonts-helper** 사용:
- https://gwfh.mranftl.com/fonts
- Google Fonts를 쉽게 다운로드하고 @font-face CSS 생성
- 언어별, 굵기별 선택 가능
- WOFF2 형식 제공

### 5.3 wget을 이용한 자동 다운로드 (선택사항)

```bash
# Google Fonts CSS 다운로드
wget "https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@300;400;500;700" -O noto-kr.css

# CSS에서 폰트 URL 추출 및 다운로드 (수동 작업 필요)
```

## 6. 최적화 전략

### 6.1 폰트 서브셋팅

**전체 폰트 대신 필요한 문자만 포함:**
- 한국어: 한글 완성형 (11,172자)
- 영어: 기본 라틴 문자 (A-Z, a-z, 0-9)
- 특수문자: 자주 사용하는 것만

**도구:**
- https://everythingfonts.com/subsetter
- pyftsubset (Python fonttools)

**효과**: 파일 크기 30-50% 감소 가능

### 6.2 폰트 포맷 선택

**권장 순서:**
1. **WOFF2** (최우선)
   - 최신 브라우저에서 지원
   - 압축률이 가장 좋음 (30-50% 작음)
   - 모든 모던 브라우저 지원

2. **WOFF** (폴백)
   - 구형 브라우저용
   - WOFF2보다 크지만 여전히 효율적

3. **TTF/OTF** (최후의 수단)
   - 구형 브라우저용
   - 파일 크기가 큼

### 6.3 비동기 로드

**현재 문제:** CSS @import는 블로킹

**개선 방법:**
```html
<!-- head.sub.php -->
<link rel="preload" href="/public/fonts/noto-sans/NotoSansKR/NotoSansKR-Regular.woff2" as="font" type="font/woff2" crossorigin>
<link rel="stylesheet" href="/public/css/fonts.css">
```

### 6.4 캐싱 최적화

**서버 설정 (.htaccess 또는 Apache 설정):**
```apache
# 폰트 파일 캐싱 (1년)
<FilesMatch "\.(woff2|woff|ttf|otf)$">
    Header set Cache-Control "max-age=31536000, public"
</FilesMatch>
```
