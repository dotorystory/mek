## 1. 현재 상황 분석

### 1.1 문제 현상

1. **페이지 로드 지연**
   - `/home/sub03_03.php` 등 서브 페이지에서 페이지 로드 시 여러 애니메이션 효과가 순차적으로 적용됨
   - 일부 브라우저에서는 페이지 상세 내용 중 일부만 표시되고 중단되는 경우 발생
   - 통신 환경이 좋지 않은 국가에서는 페이지 로드 실패 가능성 증가

2. **사용자 경험 저하**
   - 콘텐츠가 점진적으로 나타나 사용자가 전체 내용을 보기까지 시간 소요
   - 중요한 정보가 나중에 로드되어 즉시 확인 불가
   - 네트워크 타임아웃으로 일부 콘텐츠 미표시

### 1.2 기술적 원인 분석

#### 1.2.1 사용 중인 애니메이션 라이브러리

**AOS (Animate On Scroll)**
- 파일: `/home/js/aos.js`, `/home/css/aos.css`
- 용도: 스크롤 시 요소별 애니메이션 효과
- 문제: 모든 `data-aos` 속성을 가진 요소가 순차적으로 애니메이션 실행
- 영향: 페이지 로드 후 스크롤 전까지 콘텐츠 숨김 처리 가능

**Fullpage.js**
- 파일: `/home/js/fullpage.min.js`, `/home/css/fullpage_min.css`
- 용도: 메인 페이지의 풀페이지 스크롤 효과
- 사용 위치: `index.php` (메인 페이지)
- 문제: 서브 페이지에서도 초기화 코드가 포함되어 있음

**Swiper.js**
- 파일: `/home/js/swiper.js`, `/home/css/swiper.css`
- 용도: 슬라이더/캐러셀 기능
- 영향: 슬라이더 초기화 대기로 인한 지연

**Parallax.js**
- 파일: `/home/js/parallax.js`
- 용도: 패럴랙스 스크롤 효과
- 영향: 스크롤 이벤트 계산으로 인한 성능 저하

**Slick.js**
- 파일: `/home/js/slick.js`, `/home/css/slick.css`
- 용도: 슬라이더 기능
- 영향: 추가 리소스 로드 및 초기화 대기

**커스텀 애니메이션 (dxee.animation.js)**
- 파일: `/home/js/dxee.animation.js`
- 용도: 페이지별 커스텀 애니메이션
- 문제: `.animation` 클래스 요소들이 로드 후 순차적으로 나타남
- 코드 예시:
  ```javascript
  // 애니메이션 초기화 시 모든 요소를 숨김 처리
  $('.animation').addClass('animation-before')
  ```

#### 1.2.3 Main Page Anchor 작동 방식

**위치**: `/home/index.php`, `/home/js/dxee.common.js`

**구현 방식**:
```javascript
// fullpage.js 초기화
function fullPageInit() {
  if ($('#fullpage').length) new fullpage('#fullpage', {
    licenseKey: 'DXEE',
    anchors: ['section-page1', 'section-page2', ...],
    menu: '.main-page-anchor',  // 오른쪽 네비게이션
    autoScrolling: true,
    scrollingSpeed: 700,
    lazyLoad: true,
    // ...
  });
}
```

**CSS 위치**: `/home/css/style.css`
```css
.main-page-anchor {
  position: fixed;
  right: 0;
  bottom: 0;
  height: calc(100% - 90px);
  width: 90px;
  z-index: 1;
}
```

**동작**:
1. 메인 페이지(`index.php`)에서만 사용
2. 오른쪽에 고정된 네비게이션 메뉴
3. 각 섹션으로 스크롤 시 활성화 상태 변경
4. Fullpage.js와 연동하여 섹션 이동 제어

## 3. 개선 방안

### 3.1 단기 개선 방안 (Quick Win)

#### 3.1.1 애니메이션 비활성화 옵션 추가

**목표**: 통신 환경이 좋지 않은 경우 애니메이션을 건너뛰고 콘텐츠를 즉시 표시

**방법**:
1. URL 파라미터 또는 쿠키로 애니메이션 비활성화 옵션 추가
2. 예: `?no-animation=1`
3. 또는 사용자 설정 메뉴에 "빠른 로드 모드" 옵션 추가

**구현 예시**:
```php
// head.sub.php
$disable_animation = isset($_GET['no-animation']) || isset($_COOKIE['no_animation']);
if ($disable_animation) {
    define('G5_DISABLE_ANIMATION', true);
}
```

```javascript
// dxee.common.js 수정
if (typeof G5_DISABLE_ANIMATION === 'undefined' || !G5_DISABLE_ANIMATION) {
    dxee.Animation.init();
    AOS.init();
} else {
    // 애니메이션 없이 즉시 표시
    $('.animation, [data-aos]').removeClass('animation-before');
}
```

#### 3.1.2 AOS 지연 시간 단축

**현재 설정**: 기본값 사용 (약 400-600ms)

**개선**:
```javascript
AOS.init({
    duration: 400,        // 기본 1000ms → 400ms
    delay: 0,             // 지연 제거
    once: true,           // 한 번만 실행
    offset: 50            // 스크롤 트리거 거리 단축
});
```

#### 3.1.3 Google Fonts 비동기 로드

**현재**: CSS 내 `@import` (블로킹)

**개선**: `<link rel="preconnect">` + 비동기 로드
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="..." media="print" onload="this.media='all'">
```

#### 3.1.4 불필요한 라이브러리 로드 조건부 처리

**문제**: 서브 페이지에서도 메인 페이지용 라이브러리 로드

**개선**:
```php
// head.sub.php
$is_main_page = (basename($_SERVER['PHP_SELF']) == 'index.php');
if ($is_main_page) {
    // 메인 페이지용 라이브러리만 로드
    add_javascript('<script src="'.G5_JS_URL.'/fullpage.min.js"></script>', 0);
}
```

### 3.2 중기 개선 방안

#### 3.2.1 CDN 리소스 로컬화

**목표**: 외부 CDN 의존성을 최소화하여 네트워크 지연 제거

**대상**:
- Google Fonts → 로컬 폰트 파일로 변환
- jsDelivr 리소스 → 로컬 파일로 복사
- Cloudflare CDN 리소스 → 로컬 파일로 복사

**구현**:
1. 웹폰트 파일 다운로드 및 로컬 저장
2. `@font-face`로 로컬 폰트 사용
3. CSS/JS 라이브러리 로컬 파일로 대체

#### 3.2.2 애니메이션 지연 로드 (Lazy Load Animation)

**방법**: Intersection Observer API 사용
```javascript
// 화면에 보일 때만 애니메이션 초기화
const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            // 애니메이션 적용
            entry.target.classList.add('animate');
        }
    });
});

document.querySelectorAll('[data-aos]').forEach(el => {
    observer.observe(el);
});
```

#### 3.2.3 CSS 최적화

**방법**:
1. Critical CSS 인라인화 (Above the fold 콘텐츠)
2. 나머지 CSS는 비동기 로드
3. 사용하지 않는 CSS 제거

### 3.3 장기 개선 방안

#### 3.3.1 Progressive Enhancement 적용

**원칙**:
1. 기본 HTML 콘텐츠는 즉시 표시
2. CSS로 스타일링
3. JavaScript는 향상된 기능만 추가

**구현**:
- 기본 상태: 모든 콘텐츠 표시
- JavaScript 로드 후: 애니메이션 효과 추가
- JavaScript 실패 시: 기본 콘텐츠만 표시

#### 3.3.2 네트워크 상태 감지 및 자동 조절

**방법**: Network Information API 사용
```javascript
if ('connection' in navigator) {
    const connection = navigator.connection;
    if (connection.effectiveType === 'slow-2g' || connection.effectiveType === '2g') {
        // 느린 네트워크: 애니메이션 비활성화
        window.G5_DISABLE_ANIMATION = true;
    }
}
```

#### 3.3.3 서비스 워커를 통한 오프라인 지원

**현재**: `/home/sw.js` 존재하지만 제한적

**개선**:
- 정적 리소스 캐싱
- 오프라인 시 기본 콘텐츠 표시
- 네트워크 복구 시 업데이트
