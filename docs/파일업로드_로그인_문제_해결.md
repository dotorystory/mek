# 🔧 파일 업로드 로그인 문제 해결

## 📌 문제 상황

**증상**:
- 3등급 이상 회원 로그인 후에도 "로그인이 필요합니다" 오류
- elFinder connector가 403 Forbidden 응답

**콘솔 오류**:
```
connector.minimal.php?cmd=open&target=&init=1&tree=1:1 
Failed to load resource: the server responded with a status of 403 (Forbidden)
```

---

## 🔍 원인 분석

### connector.minimal.php의 include 경로 문제

#### 폴더 구조
```
/var/www/html/mekeng.com/home/
├── _common.php                    ← 목표 파일
├── plus/
│   ├── _common.php                ← plus용 공통 파일
│   ├── upload_manager.php
│   └── elfinder/
│       └── php/
│           └── connector.minimal.php  ← 이 파일에서 include
```

#### 경로 계산
```
connector.minimal.php 위치:
/var/www/html/mekeng.com/home/plus/elfinder/php/

home/_common.php까지:
elfinder/php/ → elfinder/ (../) 
→ plus/ (../../) 
→ home/ (../../../)
→ _common.php

정답: ../../../_common.php
```

---

## ✅ 해결 방법

### 수정 내용

**Before (문제)**:
```php
// connector.minimal.php
include_once('../_common.php');  
// → elfinder/_common.php (존재하지 않음) ❌
```

**After (해결)**:
```php
// connector.minimal.php
include_once('../../../_common.php');  
// → home/_common.php ✅
```
