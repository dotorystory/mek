## 🧪 테스트 방법

### 1. 일반 회원 (레벨 3 이상) 테스트

#### Step 1: 로그인
```
1. https://www.mekeng.com/home/bbs/login.php 접속
2. 레벨 3 이상 회원으로 로그인
```

#### Step 2: 파일 관리자 접속
```
https://www.mekeng.com/home/plus/upload_manager.php
```

**확인 사항**:
- ✅ 페이지 정상 로드
- ✅ 상단에 파일 통계 표시 (처음에는 0개, 0 MB)
- ✅ elFinder UI 정상 표시
- ✅ 회원 이름 및 레벨 표시

#### Step 3: 파일 업로드
```
1. "업로드" 버튼 클릭 또는 드래그 앤 드롭
2. 이미지 파일 (JPG, PNG 등) 선택
3. 업로드 완료 대기
4. 페이지 자동 새로고침 (3초 후)
```

**확인 사항**:
- ✅ 파일이 elFinder에 표시됨
- ✅ 통계가 업데이트됨 (파일 1개, 용량 증가, 업로드 1회)
- ✅ 썸네일 표시 (이미지인 경우)

#### Step 4: 폴더 생성
```
1. "새폴더" 버튼 클릭
2. 폴더명 입력 (예: "내 사진")
```

## 🔧 트러블슈팅

### Q1. "로그인이 필요합니다" 메시지가 계속 나옴

**원인**: 세션 또는 쿠키 문제

**해결**:
```bash
# 1. 세션 폴더 권한 확인
ls -la /var/www/html/mekeng.com/home/data/session/

# 2. 권한 수정
chmod 707 /var/www/html/mekeng.com/home/data/session/
```

### Q2. elFinder가 표시되지 않음

**원인**: jQuery UI 로드 실패

**해결**:
- 브라우저 콘솔(F12) 확인
- jQuery UI CDN 접근 확인
- 인터넷 연결 확인

### Q3. 파일 업로드가 안됨

**원인**: PHP 파일 크기 제한

**해결**:
```bash
# php.ini 확인
php -i | grep -E "upload_max_filesize|post_max_size"

# 필요시 수정
sudo nano /etc/php.ini
# upload_max_filesize = 500M
# post_max_size = 500M

# Apache 재시작
sudo systemctl restart httpd
```

### Q4. "권한이 없습니다" 메시지

**원인**: 회원 레벨이 3 미만

**해결**:
```sql
-- 회원 레벨 확인
SELECT mb_id, mb_name, mb_level FROM g5_member WHERE mb_id = '회원ID';

-- 레벨 상향 (필요시)
UPDATE g5_member SET mb_level = 3 WHERE mb_id = '회원ID';
```

### Q5. 통계가 0으로 표시됨

**원인**: 통계가 아직 계산되지 않음

**해결**:
```php
// upload_manager.php에서 자동 계산됨
// 또는 수동 재계산:
```

```bash
# MySQL에서 수동 재계산
mysql -u mekeng -p mek_kr
```

```sql
-- 통계 초기화
DELETE FROM g5_file_stats;

-- 로그에서 재계산 (upload_manager.php 접속 시 자동)
```
