# 📁 파일 업로드 시스템 구현 요약

## 🎯 핵심 요구사항

### 1. 권한 설정
- ✅ **회원 레벨 3 이상** 사용 가능
- ✅ 관리자(`super`)는 모든 권한

### 2. 로그 시스템
- ✅ 모든 **업로드/다운로드/삭제/접근** 기록
- ✅ 데이터베이스에 저장
- ✅ 회원별 통계 자동 계산

### 3. 주요 기능
- ✅ elFinder 기반 윈도우 탐색기 UI
- ✅ 회원별 폴더 분리 (`/upload/{회원ID}/`)
- ✅ 실시간 통계 표시
- ✅ 관리자 로그 조회 페이지
- ✅ 관리자 통계 대시보드
- ✅ 회사 내부 서버 자동 동기화

## 🗄️ 데이터베이스 테이블

### g5_file_log (로그 테이블)

| 컬럼 | 타입 | 설명 |
|------|------|------|
| fl_id | INT | 로그 ID (PK) |
| fl_mb_id | VARCHAR(20) | 회원 아이디 |
| fl_type | ENUM | UPLOAD/DOWNLOAD/DELETE/ACCESS |
| fl_filename | VARCHAR(255) | 파일명 |
| fl_filepath | VARCHAR(500) | 파일 경로 |
| fl_filesize | BIGINT | 파일 크기 (bytes) |
| fl_ip | VARCHAR(50) | IP 주소 |
| fl_datetime | DATETIME | 작업 일시 |
| fl_note | VARCHAR(500) | 비고 |

### g5_file_stats (통계 테이블)

| 컬럼 | 타입 | 설명 |
|------|------|------|
| fs_id | INT | 통계 ID (PK) |
| fs_mb_id | VARCHAR(20) | 회원 아이디 (UNIQUE) |
| fs_total_files | INT | 총 파일 개수 |
| fs_total_size | BIGINT | 총 용량 (bytes) |
| fs_upload_count | INT | 업로드 횟수 |
| fs_download_count | INT | 다운로드 횟수 |
| fs_last_upload | DATETIME | 마지막 업로드 |
| fs_last_download | DATETIME | 마지막 다운로드 |
| fs_update_datetime | DATETIME | 업데이트 일시 |

## 🔐 권한 체크 로직

```php
// 로그인 확인
if (!$is_member) {
    alert('회원만 이용할 수 있습니다.', G5_BBS_URL.'/login.php');
}

// 레벨 3 이상 확인
if ($member['mb_level'] < 3 && $is_admin != 'super') {
    alert('파일 업로드는 회원 레벨 3 이상만 이용 가능합니다.', G5_URL);
}
```

## 📊 로그 기록 함수

### 업로드 로그
```php
log_file_upload($member['mb_id'], $filename, $filepath, $filesize, $_SERVER['REMOTE_ADDR']);
```

### 다운로드 로그
```php
log_file_download($member['mb_id'], $filename, $filepath, $filesize, $_SERVER['REMOTE_ADDR']);
```

### 삭제 로그
```php
log_file_delete($member['mb_id'], $filename, $filepath, $filesize, $_SERVER['REMOTE_ADDR']);
```

### 접근 로그
```php
log_file_access($member['mb_id'], 'ACCESS', '파일 관리자', $_SERVER['REMOTE_ADDR']);
```

## 🔒 보안 설정

### .htaccess (upload 폴더)
```apache
<Files ~ "\.php$">
    Order allow,deny
    Deny from all
</Files>
Options -Indexes
```

### 파일 타입 제한
```php
$allowed_extensions = [
    'images'    => ['jpg', 'jpeg', 'png', 'gif', 'webp', 'heic'],
    'videos'    => ['mp4', 'mov', 'avi', 'mkv', 'webm'],
    'documents' => ['pdf', 'doc', 'docx', 'xls', 'xlsx', 'ppt', 'pptx', 'txt', 'hwp']
];
```

### 파일 크기 제한
- 최대 업로드: 500MB
- PHP 설정: `upload_max_filesize = 500M`
- Apache 설정: `LimitRequestBody 524288000`
