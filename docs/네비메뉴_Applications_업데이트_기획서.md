# Applications 메뉴 업데이트 기획서

## 📋 개요

현재 Applications 메뉴의 각 페이지는 내용이 매우 부족하며, 고객사가 자신의 생산 라인에 맞는 MEK의 측정 및 제어 시스템을 찾기 어려운 구조입니다. 본 문서는 Applications 메뉴의 전면적인 개편 방안을 제시합니다.

### 2. 현재 페이지의 문제점

#### 2.1 내용 부족
- 각 페이지가 단순히 제품 목록만 나열
- 생산 라인별 특성 설명 없음
- MEK 제품과의 연계 설명 부재
- 기술적 배경 정보 없음

#### 2.2 정보 구조의 한계
- **고객 관점 부재**: 고객이 자신의 생산 라인을 찾기 어려움
- **제품 매칭 어려움**: 어떤 MEK 제품이 필요한지 불명확
- **설득력 부족**: 왜 MEK 제품을 사용해야 하는지 설명 없음
- **SEO/Meta 정보 부재**: 검색 최적화 및 메타 정보 미비

#### 2.3 예시: 현재 sub02_01.php (전지)
```php
// 현재 구조: 단순 리스트만 표시
- 동박(Copper Foil)
- 분리막(Separator)
- 전극 코팅(Electrode Coating)
- 전극롤프레싱(Electrode Roll Pressing)
- 전고체배터리(Solid-state battery)
- 연료전지(Fuel cell)
```

**문제점:**
- 각 항목이 어떤 생산 라인에서 사용되는지 불명확
- MEK의 두께측정기, 피닝시스템, 표면검사기, 웹크리너 중 어떤 것이 필요한지 설명 없음
- 생산 공정의 특성과 MEK 제품의 연계 설명 부재

## 🔬 기술적 배경 정보

### 1. 필름 vs 시트 vs 2축연신

#### 1.1 필름 (Film) - 캐스팅롤 방식
**특성:**
- 얇은 두께 (일반적으로 10~500μm)
- 주로 **캐스팅롤(Casting Roll) 방식** 사용
- 압출 다이에서 나온 용융 수지를 냉각 롤에 직접 접촉시켜 냉각
- 표면 품질과 두께 균일성이 중요

**MEK 제품 적용:**
- **피닝시스템**: 용융 수지를 냉각 롤에 전기적으로 밀착시켜 균일한 두께 확보
- **두께측정기**: 실시간 두께 프로파일 측정으로 품질 관리
- **표면검사기**: 필름 표면의 결함(기포, 이물질, 스크래치) 검출
- **웹크리너**: 생산 전 표면 이물질 제거로 품질 향상

#### 1.2 시트 (Sheet) - 카렌다 방식
**특성:**
- 두꺼운 두께 (일반적으로 0.5mm 이상)
- 주로 **카렌다(Calendar) 방식** 사용
- 여러 개의 롤 사이를 통과시키며 압연하여 두께 조절
- Nip Roll을 이용한 물리적 압착 방식

**MEK 제품 적용:**
- **두께측정기**: 카렌다 롤 간격 조절을 위한 실시간 두께 모니터링
- **표면검사기**: 시트 표면의 결함 검출
- **웹크리너**: 압연 전 표면 정리

#### 1.3 2축연신 (Biaxial Stretching) - Nip Roll 방식
**특성:**
- **1차 연신**: M/D (Machine Direction, 기계방향)으로 연신
- **2차 연신**: T/D (Transverse Direction, 횡방향)으로 연신하여 면적 확대
- **Nip Roll 방식** 사용: 롤 사이에 웹을 끼워 넣고 당겨서 연신
- BOPET, BOPP, BOPE, BO Nylon 등 제조에 사용

**공정 순서:**
```
압출 → 캐스팅 → 1차 연신(M/D) → 2차 연신(T/D) → 열처리 → 권취
```

**MEK 제품 적용:**
- **두께측정기**: 연신 전후 두께 프로파일 측정으로 균일성 확보
- **피닝시스템**: 캐스팅 단계에서 냉각 롤 밀착
- **표면검사기**: 연신 과정에서 발생하는 표면 결함 검출
- **웹크리너**: 연신 전 표면 정리

### 4. 2축연신 Line (Biaxial Stretching) - sub02_09.php (신규)

#### 4.1 페이지 구조

**섹션 1: 2축연신 방식의 원리**
- **1차 연신 (M/D - Machine Direction)**: 기계방향으로 연신
- **2차 연신 (T/D - Transverse Direction)**: 횡방향으로 연신하여 면적 확대
- **Nip Roll 방식**: 롤 사이에 웹을 끼워 넣고 당겨서 연신
- 면적 확대율: 일반적으로 3~9배

**섹션 2: 2축연신 공정**
```
압출 → 캐스팅 → 피닝시스템 → 냉각 → 1차 연신(M/D) → 2차 연신(T/D) → 열처리 → 권취
```

**섹션 3: 2축연신 필름 종류**

**3.1 BOPET (Biaxially Oriented Polyethylene Terephthalate)**
- 용도: 포장재, 전자부품, 태양광 백시트
- 특성: 높은 강도, 투명도, 배리어 성능
- 두께: 12~350μm

**3.2 BOPP (Biaxially Oriented Polypropylene)**
- 용도: 포장재, 라벨, 테이프
- 특성: 우수한 투명도, 인쇄 적성
- 두께: 15~100μm

**3.3 BOPE (Biaxially Oriented Polyethylene)**
- 용도: 포장재, 농업용 필름
- 특성: 유연성, 내충격성
- 두께: 20~200μm

**3.4 BO Nylon (Biaxially Oriented Nylon)**
- 용도: 고기능 포장재, 배리어 필름
- 특성: 우수한 배리어 성능, 내열성
- 두께: 15~50μm

**섹션 4: MEK 제품 적용**

**4.1 캐스팅 단계**
- **피닝시스템**: 용융 수지를 냉각 롤에 전기적으로 밀착
  - 균일한 두께 확보로 연신 공정 안정성 향상
  - 비접촉 방식으로 표면 품질 유지

**4.2 연신 전 단계**

## 💼 설득 전략 (Why MEK?)

### 1. 기술적 우수성

#### 1.1 피닝시스템
- **비접촉 전기적 방식**: 물리적 압착이나 바람에 의한 기포 제거 방식이 아니므로 표면 마모, 온도 변화 등의 위험이 없음
- **균일한 밀착 성능**: 에어나이프나 배큐움 박스 대비 우수한 성능
- **품질과 효율**: 밀착 성능이 균일하고 우수하여 품질과 효율 모두 확보

#### 1.2 두께측정기
- **실시간 모니터링**: 폭 방향(CD) 두께 프로파일 실시간 측정
- **자동 제어 연동**: 측정 데이터를 기반으로 자동 제어 시스템 연동 가능
- **고정밀도**: 균일한 두께 확보로 불량률 감소

#### 1.3 표면검사기
- **실시간 결함 검출**: 기포, 이물질, 스크래치 등 표면 결함 실시간 검출
- **품질 관리**: 불량품 사전 차단으로 품질 향상

#### 1.4 웹크리너
- **비접촉식**: 시트, 필름 표면의 이물질을 비접촉식으로 제거
- **품질 향상**: 생산 전 표면 정리로 품질 향상

### 2. 맞춤형 솔루션

- **생산 라인별 최적화**: 각 생산 라인의 특성에 맞춘 제품 구성
- **통합 솔루션**: 여러 제품을 통합하여 제공하는 원스톱 솔루션
- **기술 지원**: 생산 라인 분석 및 최적 솔루션 제안

### 3. ROI (투자 대비 효과)

- **불량률 감소**: 실시간 모니터링으로 불량률 감소
- **생산 효율 향상**: 자동 제어 시스템으로 생산 효율 향상
- **원가 절감**: 품질 향상으로 원가 절감
- **고객 만족도 향상**: 일관된 품질로 고객 만족도 향상

    "offers": {
