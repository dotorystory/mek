# MEK+ (엠이케이 플러스) 기능 보고서

**문서 버전:** 1.0  
**작성일:** 2026-02-23  
**대상:** 엠이케이(주) & 맥엔지니어링 내부용 MEK+ 웹 통합 기능

---

## 1. 개요

**MEK+ (엠이케이 플러스)**는 회사 웹사이트 내에서 회원 전용으로 제공되는 **업무용 통합 허브**입니다.  
문서·이미지·영상 등 **파일 관리**, **영업팀 전용 게시판**, **메일/뉴스레터 발송**, **개인 프로필·권한 문의·로그인/로그아웃** 등을 한 곳에서 연결합니다.

| 구분 | 설명 |
|------|------|
| **진입 URL** | 사이트 기준 `{사이트URL}/plus/` (예: `home/plus/` 하위 경로) |
| **공통 레이아웃** | 심플 헤더/푸터 사용 (#s_top, #snb 등 일반 서브 메뉴 영역 제외) |
| **인증** | 그누보드 회원 로그인 기반. MEK+ 홈은 **회원 레벨 2 이상** 접근(미설정 시 로그인 페이지로 이동) |

---

## 2. 기능별 요약

### 2.1 파일 관리자 (문서/이미지/영상 등)

**목적:** 업로드·다운로드·폴더·파일 조회 등 **웹 기반 파일 관리**를 제공합니다.

| 항목 | 내용 |
|------|------|
| **메뉴 명** | 파일 관리자 / 파일 매니저 |
| **진입** | MEK+ 홈 → `plus/upload_manager.php` 또는 동일 경로에 연결된 링크 |
| **표시 조건** | 회원 레벨 **3 이상** (MEK+ 홈 `index.php` 기준) |
| **주요 기능** | 파일·폴더 업로드/다운로드, 목록 조회, elFinder 기반 UI 등 **(상세는 별도 구현 문서 참고)** |

#### 2.1.1 구현·화면 보고 (보완 예정)

**파일 관리자 기능 구현에 대한 상세 설명 및 스크린캡처는 이후 본 문서에 추가할 예정입니다.**

- [ ] 메인 화면 (파일 트리·작업 영역)
- [ ] 업로드/다운로드 동작 흐름
- [ ] 권한·루트 경로(등급별 등) 정책이 있는 경우 해당 화면
- [ ] 기타 운영 시 유의사항

> **참고:** `docs/` 내 기존 파일 관련 문서(`README_파일업로드_시스템_구현방안.md`, `파일업로드_시스템_구현완료.md` 등)와 연계하여 정리할 수 있습니다.

---

### 2.2 영업팀 전용 게시판

**목적:** **MEK 기술영업팀** 전용 공지·자료 공유용 게시판으로 연결합니다.

| 항목 | 내용 |
|------|------|
| **메뉴 명** | 영업팀 게시판 |
| **진입** | MEK+ 홈 → 게시판 바로가기(`board.php?bo_table=…`) |
| **표시 조건** | 회원 레벨 **3 이상** |
| **게시판 테이블** | 운영 설정에 따라 `bo_table` 값이 지정됨 (현재 허브 기준 `team` 등)** |

> ※ 실제 게시판 ID(`bo_table`)·읽기/쓰기 권한은 **관리자 > 게시판 관리**에서 확인·조정합니다.

---

### 2.3 MEK+ Mailer (개인·단체 메일 발송 및 뉴스레터)

**목적:** **개인·단체 메일 발송**, **뉴스레터 형식 발송**, SMTP 설정·발송 로그 등 **메일 운영**을 통합합니다.

| 항목 | 내용 |
|------|------|
| **메뉴 명** | MEK+ Mailer / 메일 관리자 |
| **진입** | MEK+ 홈 → `plus/mailer/` (`mailer/index.php` 등) |
| **표시 조건** | 회원 레벨 **4 이상** (MEK+ 홈 기준) |
| **주요 기능** | 뉴스레터 제목·본문, 연하장 템플릿 옵션, 첨부, **메일 발송 명단(대상)** 선택(직접 입력·구독자·회원·CSV 등), 새글 연동, 발송 로그·CSV 다운로드, 테스트 메일 등 |

> 상세 구현·메일 발송 정책은 `mail_sender.php`, `plus/mailer/index.php` 및 기존 메일 관련 `docs/` 문서를 참고합니다.

---

### 2.4 프로필·권한 문의·로그인·로그아웃

**목적:** MEK+ 내 사용자 **식별·권한 안내·세션 종료**를 제공합니다.

| 기능 | 설명 |
|------|------|
| **프로필** | MEK+ 홈 하단 카드에 **회원 ID**, **이름**, **포인트**, **프로필 이미지**(있을 경우) 표시 |
| **권한 문의** | 일반 회원: **권한 문의** 버튼 → `simple_inquiry` 등 연동 팝업(문의) |
| **설정(관리자)** | 최고관리자: 관리자 페이지 링크 등 |
| **로그아웃** | 그누보드 `logout.php`로 연결 |
| **로그인** | 미로그인 또는 레벨 미달 시 **로그인 페이지**로 이동 후 `url` 파라미터로 MEK+ 복귀 |

**표시 조건** (프로필 카드 영역): 회원 레벨 **3 이상** (MEK+ 홈 `index.php` 기준).

## 3. 기타 (MEK+ 홈에 연동된 기능)

| 메뉴 | 설명 | 표시 조건(참고) |
|------|------|----------------|
| **품질 검사** | 품질 검사표 작성·관리 (`plus/quality/`) | 레벨 9 이상 등 |

본 보고서의 **핵심 범위**는 사용자 요청에 따라 **파일 관리자·영업 게시판·Mailer·프로필/권한/로그인**이며, 품질 검사는 **별도 품질 시스템 문서**와 함께 관리하는 것을 권장합니다.
