# 품질 검사표 시스템 구현 방안

## 1. 개요

### 1.1 목적
- 한글이 포함된 엑셀/CSV 형태의 품질 검사표를 웹 기반 설문지 게시판 형태로 변환
- 태블릿 등 모바일 기기에서 품질 검사 시 사용
- 검사 결과를 데이터베이스에 저장하여 관리
- 검사 결과를 엑셀, PDF 형태로 다운로드 및 이메일 전송

### 1.2 주요 기능
1. **검사표 템플릿 관리**: 엑셀/CSV 파일 업로드 및 파싱
2. **검사표 작성**: 태블릿 친화적 UI로 검사 항목 입력
3. **사진 첨부 기능**: 검사 항목별 사진 촬영 및 첨부
4. **결제 프로세스**: 검사자 → 검수자 → 최종결제자 승인
5. **데이터 저장**: 검사 결과를 데이터베이스에 영구 보관
6. **결과 조회**: 검사 이력 열람 및 검색
7. **다운로드/전송**: 엑셀, PDF 다운로드 및 이메일 전송

- **백엔드**: PHP (그누보드 기반)

## 3. 데이터베이스 설계

### 3.1 검사표 템플릿 테이블 (`g5_quality_template`)
**용도**: 검사표 템플릿 정보 저장

**주요 필드**:
- `qt_id`: 템플릿 ID (자동증가)
- `qt_doc_id`: 문서 ID (고유 식별자)
- `qt_title`: 검사표 제목 (측정장비명)
- `qt_location`: 문서 위치
- `qt_memo`: 메모
- `qt_filepath`: 템플릿 파일 경로
- `qt_filename`: 템플릿 파일명
- `qt_created_at`: 생성 일시
- `qt_updated_at`: 수정 일시
- `qt_status`: 상태 (active/inactive)

### 3.2 검사 항목 테이블 (`g5_quality_item`)
**용도**: 검사표의 각 검사 항목 저장

**주요 필드**:
- `qi_id`: 항목 ID (자동증가)
- `qt_id`: 템플릿 ID (외래키)
- `qi_item_id`: 항목 ID (템플릿 내 순서)
- `qi_procedure`: 검사절차명
- `qi_item`: 검사항목
- `qi_method`: 검사방법
- `qi_standard`: 품질기준
- `qi_unit`: 단위
- `qi_order`: 정렬 순서

### 3.3 검사 결과 테이블 (`g5_quality_result`)
**용도**: 실제 검사 수행 결과 저장

**주요 필드**:
- `qr_id`: 결과 ID (자동증가)
- `qt_id`: 템플릿 ID (외래키)
- `qr_doc_id`: 문서 ID
- `qr_title`: 검사표 제목
- `qr_location`: 문서 위치
- `qr_memo`: 메모
- `qr_inspection_date`: 검사일시 (사용자 입력)
- `qr_review_date`: 검수일시 (사용자 입력)
- `qr_approval_date`: 최종결제일시 (사용자 입력)
- `qr_inspector`: 검사자 (회원 ID)
- `qr_inspector_name`: 검사자 이름
- `qr_reviewer`: 검수자 (회원 ID)
- `qr_reviewer_name`: 검수자 이름
- `qr_final_approver`: 최종결제자 (회원 ID)
- `qr_final_approver_name`: 최종결제자 이름
- `qr_status`: 상태 (draft/inspected/reviewed/approved)
- `qr_created_at`: 생성 일시
- `qr_updated_at`: 수정 일시

### 3.4 검사 결과 상세 테이블 (`g5_quality_result_detail`)
**용도**: 각 검사 항목별 결과 저장

**주요 필드**:
- `qrd_id`: 상세 ID (자동증가)
- `qr_id`: 결과 ID (외래키)
- `qi_id`: 항목 ID (외래키)
- `qrd_result`: 검사결과 (값)
- `qrd_reviewer_check`: 검수자확인 (Y/N) -> 체크박스
- `qrd_note`: 비고
- `qrd_order`: 정렬 순서

### 3.6 검사 사진 테이블 (`g5_quality_photo`)
**용도**: 검사 항목별 첨부 사진 저장

**주요 필드**:
- `qp_id`: 사진 ID (자동증가)
- `qrd_id`: 결과 상세 ID (외래키)
- `qr_id`: 결과 ID (외래키)
- `qi_id`: 항목 ID (외래키)
- `qp_filename`: 원본 파일명
- `qp_filepath`: 저장 경로
- `qp_filesize`: 파일 크기 (bytes)
- `qp_width`: 이미지 너비 (px)
- `qp_height`: 이미지 높이 (px)
- `qp_thumbnail`: 썸네일 경로
- `qp_uploaded_at`: 업로드 일시
- `qp_order`: 정렬 순서

### 3.5 결제 이력 테이블 (`g5_quality_approval`)
**용도**: 결제 프로세스 이력 저장

**주요 필드**:
- `qa_id`: 결제 ID (자동증가)
- `qr_id`: 결과 ID (외래키)
- `qa_step`: 결제 단계 (inspector/reviewer/final)
- `qa_approver`: 결제자 (회원 ID)
- `qa_approver_name`: 결제자 이름
- `qa_status`: 상태 (approved/rejected)
- `qa_comment`: 결제 의견
- `qa_approved_at`: 결제 일시

## 4. 기능 상세 설계

### 4.1 템플릿 관리 (관리자)

#### 4.1.1 엑셀/CSV 업로드
- **위치**: `/home/plus/quality/template_upload.php`
- **저장 경로**: `/var/www/html/upload/quality/files/`
- **기능**:
  - 엑셀(.xlsx, .xls) 또는 CSV 파일 업로드
  - 업로드된 파일은 `/upload/quality/files/` 폴더에 저장
  - 파일명 형식: `template_{템플릿ID}_{타임스탬프}.{확장자}` 또는 `template_{날짜시간}_{고유ID}.{확장자}`
  - 파일 인코딩 자동 감지 (UTF-8, EUC-KR)
  - 한글 포함 데이터 처리
  - 업로드된 파일 파싱 및 검증

#### 4.1.2 템플릿 파싱
- **처리 순서**:
  1. **첫 번째 행**: 문서ID (1행 1열에 직접 입력) / 검사표제목 / (제목 내용) / 문서위치 / (문서 위치 경로) / 메모 / (메모 내용)
     - 예시: `Edit.211101, A-측정장비 제작품질 검수서(X.B.L), /서버/제조기술/두께측정기/문서자료, (메모를 입력하세요.)`
  2. **두 번째 행**: 관리자 / 검사자 / (검사자 이름) / 검수자 / (검수자 이름) / 최종결제자 / (최종결제자 이름)
     - 예시: `관리자, 검사자, 홍길동, 검수자, 신사임당, 최종결제자, 세종대왕`
  3. **세 번째 행**: 일시 / 검사일 / (검사일 직접입력 혹은 달력에서 선택) / 검수일 / (검수일 직접입력 혹은 달력에서 선택) / 최종결제일 / (최종결제일 직접입력 혹은 달력에서 선택)
     - 웹의 경우 입력일은 사용자의 입력을 받고, 수정일은 DB에 자동 기록
  4. **네 번째 행**: ID, 검사절차명, 검사항목, 검사방법, 품질기준, 단위, 검사결과, 첨부파일, 비고 (메뉴명 배치)
     - 검사결과 컬럼: √ (체크박스 여부 - 합격/불합격)
     - 첨부파일 컬럼: '없음' 또는 '📷' (사진 첨부 여부)
  5. **다섯 번째 행부터**: 검사 항목 데이터

#### 4.1.3 템플릿 목록
- **위치**: `/home/plus/quality/template_list.php`
- **기능**:
  - 등록된 템플릿 목록 조회
  - 템플릿 수정/삭제
  - 템플릿 미리보기

### 4.2 검사표 작성 (태블릿 UI)

#### 4.2.1 검사표 선택
- **위치**: `/home/plus/quality/inspection.php`
- **기능**:
  - 템플릿 목록에서 검사표 선택
  - 검사표 정보 표시 (제목, 위치, 메모)

#### 4.2.2 검사 항목 입력
- **UI 구성**:
  - 반응형 디자인 (태블릿 최적화)
  - 터치 친화적 입력 필드
  - 스크롤 가능한 긴 목록 처리
  - 자동 저장 기능 (임시 저장)

#### 4.2.3 검사 항목 필드
- **ID**: 자동 표시 (읽기 전용)
- **검사절차명**: 자동 표시 (읽기 전용)
- **검사항목**: 자동 표시 (읽기 전용)
- **검사방법**: 자동 표시 (읽기 전용)
- **품질기준**: 자동 표시 (읽기 전용)
- **단위**: 자동 표시 (읽기 전용)
- **검사결과**: 체크박스 (√) - 합격/불합격 여부
- **첨부파일**: 사진 첨부 여부 표시
  - 사진이 있는 경우: 📷
  - 사진이 없는 경우: (없음)
- **비고**: 텍스트 입력

#### 4.2.6 사진 촬영 및 첨부
- **위치**: `/home/plus/quality/inspection.php` (검사 항목별)
- **저장 경로**: `/var/www/html/upload/quality/`
  - 원본 사진: `/var/www/html/upload/quality/original/`
  - 썸네일: `/var/www/html/upload/quality/thumbnail/`
- **기능**:
  - 카메라 촬영 (태블릿 카메라 앱 연동)
  - 갤러리에서 사진 선택
  - 여러 장 첨부 가능 (항목당 최대 5장)
  - 사진 크기 제한: 최대 5MB
  - 이미지 해상도 제한: 최대 2048px × 2048px
  - 자동 리사이징: 업로드 시 자동으로 최적화된 크기로 변환
  - 썸네일 생성: 목록 표시용 썸네일 자동 생성
  - 사진 미리보기: 업로드 전 미리보기
  - 사진 삭제: 업로드된 사진 삭제 가능

#### 4.2.4 검사 정보 입력
- **검사일시**: 날짜/시간 선택기
- **검사자**: 현재 로그인 사용자 (자동)
- **문서 위치**: 템플릿에서 가져오기 (수정 가능)
- **메모**: 텍스트 입력

#### 4.2.5 저장 및 제출
- **임시 저장**: 검사 중간에 저장 가능
- **최종 제출**: 검사 완료 후 제출 (검수자에게 전달)

#### 4.3.3 최종결제자 단계

### 4.4 결과 조회

#### 4.4.1 검사 이력 목록
- **위치**: `/home/plus/quality/result_list.php`
- **기능**:
  - 검사 결과 목록 조회

### 4.5 다운로드 및 전송

  - 검사 결과를 PDF 형식으로 변환
  - 인쇄용 레이아웃
  - 한글 폰트 지원
  - 파일명: `품질검사표_{문서ID}_{검사일시}.pdf`

#### 4.5.3 이메일 전송
- **위치**: `/home/plus/quality/send_email.php`
- **기능**:
  - 검사 결과를 이메일로 전송

  - 수신자 지정 (검사자, 검수자, 최종결제자 등)
  - 이메일 본문에 검사 요약 정보 포함

- **반응형 디자인**: 768px 이상 태블릿 화면 최적화

## 13. 참고 사항

### 13.1 엑셀 파일 형식 예시
- **첫 번째 행**: 문서ID (1행 1열에 직접 입력) / 검사표제목 / (제목 내용) / 문서위치 / (문서 위치 경로) / 메모 / (메모 내용)
  - 예시: `Edit.211101, A-측정장비 제작품질 검수서(X.B.L), /서버/제조기술/두께측정기/문서자료, (메모를 입력하세요.)`
- **두 번째 행**: 관리자 / 검사자 / (검사자 이름) / 검수자 / (검수자 이름) / 최종결제자 / (최종결제자 이름)
  - 예시: `관리자, 검사자, 홍길동, 검수자, 신사임당, 최종결제자, 세종대왕`
- **세 번째 행**: 일시 / 검사일 / (검사일 직접입력 혹은 달력에서 선택) / 검수일 / (검수일 직접입력 혹은 달력에서 선택) / 최종결제일 / (최종결제일 직접입력 혹은 달력에서 선택)
  - 웹의 경우 입력일은 사용자의 입력을 받고, 수정일은 DB에 자동 기록
- **네 번째 행**: ID, 검사절차명, 검사항목, 검사방법, 품질기준, 단위, 검사결과, 첨부파일, 비고 (메뉴명 배치)
  - 검사결과 컬럼: √ (체크박스 여부 - 합격/불합격)
  - 첨부파일 컬럼: '없음' 또는 '📷' (사진 첨부 여부)
- **다섯 번째 행부터**: 검사 항목 데이터
  - 예시: `1, 1차 검사, 가로프레임 길이 (절대오차), 줄자, '< ±1', mm, √, (없음), (비고 입력란)`
  - 예시: `2, 1차 검사, 가로프레임 길이 (Pair 상대오차), Pair 비교, '< 0.5', mm, , 📷, `

### 13.2 한글 인코딩 처리
- 엑셀 파일: UTF-8 또는 EUC-KR 자동 감지
- CSV 파일: BOM 유무 확인
- 데이터베이스: UTF-8 사용

### 13.3 태블릿 최소 사양
- 화면 크기: 768px × 1024px 이상
- 브라우저: Chrome, Safari 최신 버전
- 터치 지원 필수
- 카메라 지원 (사진 촬영 기능 사용 시)

### 13.4 사진 첨부 규격
- **파일 형식**: JPG, JPEG, PNG, GIF
- **최대 파일 크기**: 5MB
- **최대 해상도**: 2048px × 2048px
- **자동 리사이징**: 업로드 시 자동으로 최적화된 크기로 변환
- **썸네일 크기**: 150px × 150px (목록 표시용)
- **항목당 최대 개수**: 5장
