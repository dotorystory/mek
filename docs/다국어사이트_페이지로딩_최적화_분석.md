# 다국어 사이트 페이지 로딩 최적화 분석

## 현재 문제점

### 1. 콘솔 에러 분석
```
sub03_03.php:27  GET https://www.mekeng.com/public/css/fullpage_min.css?ver=25103108 net::ERR_ABORTED 404 (Not Found)
jquery-3.7.0.min.js?ver=220620:2 Uncaught SyntaxError: Unexpected token '&'
dxee.common.js?ver=220620:40 Uncaught ReferenceError: tabActive is not defined
```

**원인:**
- 모든 서브 페이지에서 `fullpage_min.css`, `fullpage.min.js`, `dxee.common.js`, `slick.js` 등을 로드
- 이 스크립트들은 **index.php (메인 페이지)에만 필요**
- 서브 페이지에는 불필요하며, 오히려 에러 발생

### 2. 각 라이브러리 용도

#### A. fullpage.js (fullpage.min.js + fullpage_min.css)
- **용도**: 메인 페이지의 전체 화면 섹션 스크롤 효과
- **사용 위치**: `home/index.php`의 `<div id="fullpage">` 컨테이너
- **필요 페이지**: **index.php만**
- **서브 페이지 필요 여부**: ❌ 불필요

#### B. slick.js (slick.js + slick.css)
- **용도**: 이미지 캐러셀/슬라이더 (파트너 로고, 인증서 슬라이드)
- **사용 위치**: 
  - `home/skin/latest/swiper_pic_block/latest.skin.php` (파트너 로고)
  - `home/skin/latest/lat_pat_new/latest.skin.php` (특허/인증서)
- **필요 페이지**: **index.php만** (메인 페이지의 파트너/인증서 섹션)
- **서브 페이지 필요 여부**: ❌ 불필요 (서브 페이지에는 슬라이더 없음)

#### C. dxee.common.js
- **용도**: 메인 페이지의 공통 기능 (탭, 모바일 메뉴, sticky 헤더)
- **사용 위치**: 주로 메인 페이지
- **필요 페이지**: **index.php만**
- **서브 페이지 필요 여부**: ❌ 불필요 (서브 페이지는 단순 구조)

#### D. swiper.js (swiper.js + swiper.css)
- **용도**: 메인 비주얼 배너 슬라이드
- **사용 위치**: `home/js/script.js` - 메인 페이지 상단 배너
- **필요 페이지**: **index.php만**
- **서브 페이지 필요 여부**: ❌ 불필요

#### E. parallax.js
- **용도**: 패럴랙스 스크롤 효과
- **사용 위치**: 메인 페이지 일부 섹션
- **필요 페이지**: **index.php만**
- **서브 페이지 필요 여부**: ❌ 불필요

#### F. aos.js (aos.js + aos.css)
- **용도**: 스크롤 애니메이션 (fade-up, fade-in 등)
- **사용 위치**: **모든 페이지** (서브 페이지 포함)
- **필요 페이지**: **모든 페이지** ✅
- **서브 페이지 필요 여부**: ✅ 필요 (data-aos 속성 사용 중)

## 해결 방안

### 1. 서브 페이지 단순화
서브 페이지는 다음만 필요:
- ✅ AOS (스크롤 애니메이션)
- ✅ 기본 CSS (style.css)
- ❌ fullpage.js 불필요
- ❌ slick.js 불필요
- ❌ dxee.common.js 불필요
- ❌ swiper.js 불필요
- ❌ parallax.js 불필요

### 2. 다국어 사이트 head.sub.php 수정 필요

**현재 상태 (en/head.sub.php):**
```php
// 모든 페이지에 로드 중 (문제!)
add_javascript('<script src="'.G5_JS_URL.'/dxee.common.js"></script>', 0);
add_javascript('<script src="'.G5_JS_URL.'/fullpage.min.js"></script>', 0);
add_javascript('<script src="'.G5_JS_URL.'/slick.js"></script>', 0);
add_stylesheet('<link rel="stylesheet" href="'.G5_CSS_URL.'/fullpage_min.css">', 0);
add_stylesheet('<link rel="stylesheet" href="'.G5_CSS_URL.'/slick.css">', 0);
```

**수정 필요:**
```php
// 메인 페이지 확인
$is_main_page = (basename($_SERVER['PHP_SELF']) == 'index.php' && !preg_match('#/plus/#', $_SERVER['SCRIPT_NAME']));

// 공통 스크립트 (모든 페이지)
add_javascript('<script src="'.G5_JS_URL.'/aos.js"></script>', 0);

// 메인 페이지 전용 스크립트
if ($is_main_page) {
    add_javascript('<script src="'.G5_JS_URL.'/dxee.common.js"></script>', 0);
    add_javascript('<script src="'.G5_JS_URL.'/dxee.animation.js"></script>', 0);
    add_javascript('<script src="'.G5_JS_URL.'/dxee.slide.js"></script>', 0);
    add_javascript('<script src="'.G5_JS_URL.'/fullpage.min.js"></script>', 0);
    add_javascript('<script src="'.G5_JS_URL.'/swiper.js"></script>', 0);
    add_javascript('<script src="'.G5_JS_URL.'/slick.js"></script>', 0);
    add_javascript('<script src="'.G5_JS_URL.'/script.js"></script>', 0);
    add_stylesheet('<link rel="stylesheet" href="'.G5_CSS_URL.'/fullpage_min.css">', 0);
    add_stylesheet('<link rel="stylesheet" href="'.G5_CSS_URL.'/swiper.css">', 0);
    add_stylesheet('<link rel="stylesheet" href="'.G5_CSS_URL.'/slick.css">', 0);
} else {
    // 서브 페이지용 간소화된 스크립트
    add_javascript('<script src="'.G5_JS_URL.'/dxee.animation.js"></script>', 0);
}

// 공통 CSS (모든 페이지)
add_stylesheet('<link rel="stylesheet" href="'.G5_CSS_URL.'/aos.css">', 0);
add_stylesheet('<link rel="stylesheet" href="'.G5_JS_URL.'/font-awesome/css/font-awesome.min.css">', 0);
add_stylesheet('<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@48,400,0,0">', 0);
add_stylesheet('<link rel="stylesheet" href="'.G5_CSS_URL.'/style.css">', 0);
add_stylesheet('<link rel="stylesheet" href="'.G5_CSS_URL.'/mo_style.css">', 0);
```

## 예상 효과

### 1. 페이지 로드 속도 개선
- 서브 페이지에서 불필요한 JS/CSS 제거 (약 500KB 이상 절감)
- 네트워크 요청 수 감소 (7개 → 2개)
- 스크립트 파싱 시간 단축

### 2. 에러 제거
- `fullpage_min.css 404 에러` 제거
- `tabActive is not defined` 에러 제거
- jQuery 충돌 에러 제거

### 3. 서브 페이지 표시 방식
- **변경 전**: fullpage.js로 인한 복잡한 스크롤 제어 시도 → 에러 발생
- **변경 후**: 일반 HTML 흐름대로 div, section이 순차적으로 표시
- **AOS 효과**: 스크롤 시 fade-up 등 애니메이션은 유지 (data-aos 속성)

### 4. 메인 페이지 기능 유지
- ✅ Fullpage.js 전체 화면 스크롤
- ✅ Swiper 메인 비주얼 슬라이드
- ✅ Slick 파트너/인증서 캐러셀
- ✅ Parallax 효과
- ✅ AOS 스크롤 애니메이션

## 결론

**서브 페이지는 단순하게:**
- 일반 HTML 문서처럼 div, section이 위에서 아래로 순차 표시
- AOS로 스크롤 시 부드러운 fade-up 애니메이션만 적용
- 복잡한 fullpage, slick, parallax 등은 메인 페이지에만 사용

**이렇게 하면:**
- 페이지 로드 속도 빠름
- 에러 없음
- 통신 환경이 좋지 않은 국가에서도 안정적으로 표시
