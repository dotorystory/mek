```

→ 회원 레벨을 3 이상으로 변경

#### 2-2. 파일 관리자 접속
```
1. 레벨 3 이상 회원으로 로그인
2. https://www.mekeng.com/home/plus/upload_manager.php 접속
```

**확인 사항**:
- ✅ 페이지 정상 로드
- ✅ 통계 표시 (0개, 0 MB, 0회)

#### 2-3. 파일 업로드 (방법 1: 드래그 앤 드롭)
```
1. PC에서 이미지 파일 준비 (예: test.jpg)
2. elFinder 영역으로 드래그
3. 파일 업로드 진행률 확인
4. 업로드 완료 대기
5. 3초 후 페이지 자동 새로고침
```

**확인 사항**:
- ✅ 파일이 목록에 표시됨
- ✅ 썸네일 생성 (이미지인 경우)
- ✅ 통계 업데이트:
  - 파일 개수: 1개
  - 용량: 파일 크기만큼 증가
  - 업로드 횟수: 1회
  - 마지막 업로드: 현재 시간

#### 2-4. 파일 업로드 (방법 2: 버튼)
```
1. "업로드" 버튼 클릭
2. 파일 선택 대화상자에서 파일 선택 (예: document.pdf)
3. 업로드 완료 대기
```

**확인 사항**:
- ✅ PDF 파일 업로드 성공
- ✅ 통계 업데이트 (파일 2개)

#### 2-5. 폴더 생성 및 정리
```
1. "새폴더" 버튼 클릭
2. 폴더명 입력 (예: "회사 자료")
3. 파일을 폴더로 드래그하여 이동
```

**확인 사항**:
- ✅ 폴더 생성 성공
- ✅ 파일 이동 성공

#### 2-6. 파일 다운로드
```
1. 파일 선택 (클릭)
2. "다운로드" 버튼 클릭
3. 파일 저장 확인

**확인 사항**:
- ✅ 파일 다운로드 성공

## 🔍 데이터베이스 로그 확인

### 업로드 로그 확인
```sql
SELECT 
    fl_id,
    fl_mb_id,
    fl_type,
    fl_filename,
    ROUND(fl_filesize/1024/1024, 2) as size_mb,
    fl_ip,
    fl_datetime
FROM g5_file_log 
WHERE fl_type = 'UPLOAD'
ORDER BY fl_datetime DESC 
LIMIT 10;
```

### 회원별 통계 확인
```sql
SELECT 
    fs_mb_id,
    fs_total_files,
    ROUND(fs_total_size/1024/1024, 2) as total_mb,
    fs_upload_count,
    fs_download_count,
    fs_last_upload
FROM g5_file_stats 
ORDER BY fs_total_size DESC;
```

### 활동 타입별 집계
```sql
SELECT 
    fl_type,
    COUNT(*) as count,
    ROUND(SUM(fl_filesize)/1024/1024, 2) as total_mb
FROM g5_file_log 
GROUP BY fl_type;
```

**예상 결과**:
```
fl_type  | count | total_mb
---------|-------|----------
UPLOAD   |    10 |   45.50
DOWNLOAD |     5 |   22.75
ACCESS   |     3 |    0.00
DELETE   |     2 |    5.25
```

## 🐛 예상되는 문제 및 해결

### 문제 1: elFinder가 빈 화면

**원인**: jQuery UI 로드 실패

**해결**:
```javascript
// 브라우저 콘솔(F12)에서 확인
console.log(typeof jQuery);  // "function" 출력되어야 함
console.log(typeof jQuery.ui);  // "object" 출력되어야 함
```

**해결 방법**:
- 인터넷 연결 확인
- CDN 접근 가능 여부 확인

### 문제 2: 파일 업로드 후 통계가 0

**원인**: recalculate_file_stats() 함수 오류

**해결**:
```sql
-- 수동으로 통계 재계산
DELETE FROM g5_file_stats WHERE fs_mb_id = '회원ID';
```

그 후 upload_manager.php 재접속 (자동 재계산)

### 문제 3: 한글 파일명 깨짐

**원인**: 파일시스템 인코딩 문제

**해결**:
```bash
# 파일시스템 로케일 확인
locale

# UTF-8 확인
# LANG=en_US.UTF-8 또는 ko_KR.UTF-8
```

### 문제 4: "Connection failed" 오류

**원인**: connector.minimal.php 오류

**확인**:
```bash
# Apache 에러 로그
tail -50 /var/log/httpd/error_log | grep elFinder
```

**해결**:
- 파일 권한 확인
- PHP 에러 확인

## 📞 문의 및 지원

### 문제 발생 시 확인 사항

1. **Apache 에러 로그**:
   ```bash
   tail -100 /var/log/httpd/error_log
   ```

2. **PHP 에러 로그**:
   ```bash
   tail -100 /var/log/php-fpm/error.log
   ```

3. **브라우저 콘솔**:
   ```
   F12 → Console 탭
   ```

4. **데이터베이스 연결**:
   ```bash
   mysql -u mekeng -p'mekeng1!' mek_kr -e "SELECT 1"
   ```
