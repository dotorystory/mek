## 메일 본문

안녕하세요.

다우오피스를 사용하는 회사의 온라인 담당자입니다.

회사 홈페이지의 문의 기능을 통해 고객이 남긴 문의 내용을 메일로 회신받고 있는데, 해당 메일을 저희가 사용 중인 다우오피스 회사 메일로 수신하지 못하는 상황입니다.

서버 로그를 확인한 결과, **다우오피스 측에서 저희 회사 홈페이지 서버 IP의 메일 수신을 제한**하고 있는 것으로 보입니다.  
발신 서버 IP **172.234.92.172**가 다우오피스 측 **"IP Rate Control"**로 제한되어 전달 지연 또는 실패가 발생하고 있어, 고객 문의 메일을 제때 받지 못하고 있습니다.

이로 인해 업무에 지장이 있어, **해당 IP에 대한 메일 수신 제한 해제**를 요청드립니다.

아래 정보로 조치 부탁드립니다.

- **회사명:** MEK  
- **요청 내용:** MEK 회사 홈페이지 발신 메일 수신 제한 해제  
- **대상 IP:** 172.234.92.172 (회사 홈페이지/문의 메일 발송 서버)

빠른 조치 부탁드립니다.  
감사합니다.
